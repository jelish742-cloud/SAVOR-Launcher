# SAVOR-Launcher
⚡ A fast, beautiful, and smart launcher for Minecraft.

🪽 Installs game versions and mod loaders in a couple of clicks, automatically configures Java, explains game crashes, and lets you design skins right inside the app.


📦 Built-in mods Catalog: Install and update mods, worlds, resource packs, shaders, and modpacks directly within the launcher 🌐


🎨 3D Skin Editor


🖌️ 3D & 2D editing (Steve / Alex, dual layers, full toolset)


📁 PNG import & export


☁️ One-click Microsoft skin upload


🌐 Ely.by support & skin lookup by username

⚡ One-click installation of Forge, OptiFine, Fabric, and Forge + OptiFine
⚙️ Automatic compatibility setup for modded profiles

## 💬 Feedback & Bug Reports

Found a bug or have an idea? Please open an issue:
👉 https://github.com/jelish742-cloud/SAVOR-Launcher/issues

When reporting a problem, please include:
- Your Windows version and SAVOR Launcher version
- Minecraft version and loader (Vanilla / Forge / Fabric / OptiFine)
- What you did and what happened instead
- The log file `%APPDATA%\.savor\logs\last-launch.log` (or use the **LOG** button in the launcher)
- For sign-in problems: the last lines of `%APPDATA%\.savor\launcher.log`

> ⚠️ Never post your passwords or account tokens. The launcher removes tokens from `last-launch.log`, but check the file before sharing it.
