### v1.0.4 update:
➕ 🧠 Smarter crash analysis


➕ 🔍 Recognizes far more situations: library conflicts, incompatible mods, wrong Java version, mods built for the wrong loader (Forge/Fabric), duplicate mods, network problems, low disk space, files locked by antivirus


➕🎯 Pinpoints "suspect" mods using the crash report and stack trace


➕ 📦 If a library mod is missing (Fabric API, Kotlin, Cloth Config, Architectury, GeckoLib, etc.), the launcher offers to install it for you


➕ 🛠️ No more "error not recognized" dead ends: even when the exact cause is unknown, the launcher suggests fixes from gentlest to most drastic, and every one of them can be undone


➕ ✨ The "Fix" button now does the work itself: disables mods, switches Java, resets launch options, reinstalls the version


➕ ✅ Forge 1.7.10 – 1.12.2 now launches correctly. Previously the game started without Forge or crashed with errors like `NoSuchMethodError` (joptsimple, guava) and `Could not find or load main class`


➕ 📚 The launcher now parses the Forge installer itself and downloads any missing libraries


➕ 🖼️ Fixed a wrong asset index on these versions


➕ New "Game versions" section in Settings with a "Delete selected version" button


➕ Handy for a clean reinstall of a broken version


➕ 🚫 Forge below 1.7.2 has been removed from the list: those versions are unstable


➕ 📜 EULA update
